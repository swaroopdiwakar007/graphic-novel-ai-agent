# Art style

Fill in once per project, then reuse the **style prompt** unchanged for every panel.

## Style prompt (copy into every image request)
> [Medium and look, e.g. "ink and watercolor graphic novel illustration, bold linework, muted earthy palette"]

## Decisions
- **Line**: weight, inking style
- **Color**: palette (list 5-8 hex codes), lighting mood
- **Rendering**: flat / cel-shaded / painterly
- **Backgrounds**: detail level, recurring locations
- **Lettering**: font style for dialogue, captions, SFX
- **Avoid**: anything that breaks the look

## Characters
One block per main character in `story-bible/`, with fixed description (age, build, hair, face, outfit, colors) that is pasted into every prompt featuring them.
