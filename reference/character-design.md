# Character design guide

Design each main character once, in `story-bible/`, then reuse the exact same description in every panel prompt. Use this template per character; keep it under one page.

## Template

```
Name:
Role in the story:
Personality (3 words):
Age / build / height relative to others:
Silhouette: the shape you could recognize in black (hat, hair, coat, tool)
Shape language: round and soft / angular and sharp / mixed
Face: eye shape, brows, nose, any marks
Hair:
Costume: main outfit, signature item (the one thing always visible)
Palette: 3 to 5 colors with hex codes (coat, accent, skin, hair, shoes)
Expression set: neutral, worried, surprised, determined (add happy, angry, amused as needed)
Views: front, side, back, three-quarter
Voice and mannerisms: how they speak and move
Prompt snippet: one sentence pasted unchanged into every panel prompt
```

## Rules of thumb
- **Silhouette first.** If two characters share a silhouette, change a hat, hair or coat length.
- **Color blocking.** Give each main character a dominant color so they read at a glance, even small in a wide shot.
- **One signature item.** A scarf, lantern or hat that anchors identity across costumes.
- **Contrast the cast.** Vary height, build and shape language between characters.
- **Expressions fixed.** Draw the expression set once; reuse its eyes, brows and mouth shapes.
- **Costume changes** get their own entry with a new prompt snippet, so the change is deliberate.
- **Scale chart.** Place characters side by side once so heights stay consistent.

## Consistency checklist (before each page is approved)
- Same hair, outfit and palette as the character sheet?
- Signature item present?
- Height relative to others unchanged?
- Expression drawn from the fixed set?
