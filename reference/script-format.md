# Script format

One file per page: `script/page-NN.md`.

```
# Page 07  (5 panels)
Layout: <key from reference/panel-templates.md, e.g. hero-row>
Beat: <which story-bible beat this covers>

## Panel 1
Shot: wide establishing
Setting: <location, time of day, light>
Action: <what we see, who is where, expressions>
Caption: "<narration, or none>"
Dialogue:
  MARA (worried): "<line>"
SFX: CREAK

## Panel 2
...
```

Rules: one moment per panel, 25 words or fewer of dialogue per balloon, name every character in frame, and describe only what can be drawn.
